# IPSC Insight Timer

En enkel mobiltilpasset nedtellingsapp for iPhone/Safari.

## Funksjoner

- Velg 5, 4 eller 3 minutter
- Alarm ved 1 minutt igjen
- Alarm når tiden er ute
- Start, pause, restart og reset
- Mørkt IPSC-inspirert mobilutseende
- Lyd aktiveres med trykk, slik iPhone krever

## Kjør lokalt

```bash
npm install
npm run dev
```

Åpne adressen som vises i terminalen, vanligvis:

```text
http://localhost:5173
```

## Bygg for publisering

```bash
npm run build
```

## Publiser på GitHub

```bash
git init
git add .
git commit -m "Initial IPSC timer app"
git branch -M main
git remote add origin https://github.com/DITT_BRUKERNAVN/ipsc-timer.git
git push -u origin main
```
